# 전산직 합격 루틴

9급 전산직 준비를 위한 하루 루틴 체크 페이지입니다.

- **오늘 루틴**: 지금 단계에 맞는 아침·오후·저녁 공부 블록 체크 (편집 가능)
- **디데이**: 한능검 제82회 일정 기본 포함, 시험 일정 직접 추가 가능
- **이번 주**: 요일별 공부 시간과 과목별 누적 시간
- **로드맵**: 2026.11 기초 다지기부터 2030.08 본시험까지 7단계, 날짜에 따라 루틴 자동 전환

루틴의 80% 이상을 채운 날이 이어지면 연속 일수가 올라갑니다. 기록은 브라우저 localStorage에만 저장됩니다.
영어 블록은 [영어 일일 할당량](https://chaehyun05.github.io/english/) 페이지로 연결됩니다.
